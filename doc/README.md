# 文档总览

> 本文件是全仓库文档的**唯一总入口**：汇总所有文档的路径、用途与阅读时机。AI 助手与开发者从这里查找一切资料。

## 文档规范

- 只记录**关键内容**：架构决策、重要踩坑、方案取舍，方便日后回溯；不记流水账。
- 本仓库是**公开仓库**：密钥、个人路径、内部资料、未公开的合作信息一律不写入。
- 新增文档后必须回填本索引。

## 文档维护规则

- 平台无关的关键事件 → 追加到 [diary.md](diary.md)；平台相关 → 写入对应 `<平台>/doc/`。
- 新建任何文档（含根目录新文件）→ 在上方地图中登记。
- `.workbuddy/` 为 AI 助手本地工作区，**不提交**，其内容通过本目录文档交接。
